## 🧩 Main Features

### 👤 Personal Introduction

The portfolio introduces who I am, what I enjoy doing and the areas of technology that interest me.

It combines information about myself with interactive elements and a custom graphical interface.

### 💾 Personalized Experience

Visitors can enter their names to personalize parts of the website.

The information is stored locally in the browser using:

`localStorage`

This allows the website to remember the visitor's name without requiring an account.

### 🎂 Automatic Age Calculation

My age is calculated automatically using JavaScript.

This means the website can display an updated age without requiring manual changes every year.

### 🧭 Interactive Navigation

The portfolio includes a navigation system that allows visitors to move between its main sections.

JavaScript is used to manage interactive behavior and visual effects.

### ✉️ Contact System

Visitors can compose an email directly through the website interface.

The system generates an email using the information entered by the visitor and opens it through the device's configured email application.

It uses the `mailto:` protocol rather than a dedicated email backend.

### 📅 Image of the Day

The portfolio includes a date-based image system.

It uses a JSON file to manage images and content associated with particular dates.

This makes it possible to display different content depending on the current day.

### 📱 Responsive Layout

The interface is designed to adapt to different screen sizes.

Additional JavaScript functionality detects device and display information.
