# 👋 Thomas Battaglia — Portfolio

Benvenuto nel repository del mio **portfolio personale**!

Questo sito nasce come uno spazio personale in cui presentarmi, raccontare ciò che mi interessa e raccogliere alcuni dei miei progetti legati soprattutto a **programmazione, matematica e tecnologia**.

> 🚀 Questa repository contiene la **Versione 1** del portfolio.  
> La **V2 è in sviluppo**.

---

## 🌐 Il progetto

Il portfolio non è soltanto una pagina di presentazione.

Contiene diverse sezioni e piccole funzionalità interattive realizzate direttamente in HTML, CSS e JavaScript, oltre ad alcune parti in PHP.

Tra le funzionalità presenti:

- 👤 Presentazione personale
- 💻 Sezioni dedicate alla programmazione e ai miei interessi
- 🧮 Contenuti dedicati alla matematica
- 📅 Sistema **"Immagine del giorno"**
- 👋 Messaggi personalizzati utilizzando il nome del visitatore
- 💾 Salvataggio del nome tramite `localStorage`
- 🎂 Calcolo automatico dell'età
- 🧭 Navigazione dinamica tra le sezioni
- ✉️ Composizione di email direttamente dal sito
- 🖼️ Visualizzazione dedicata delle immagini
- 🔍 Metadati SEO e Open Graph
- 🚧 Pagina dedicata ai contenuti non ancora disponibili
- ❌ Pagina di errore personalizzata
